# Airplane Shooting Game

A 3D airplane shooting game developed in **C++ and OpenGL** for a Computer Graphics course project.

## Features

- Custom GLSL vertex and fragment shaders
- Phong lighting
- Dynamic floodlight
- Camera control
- Airplane movement and rotation
- Mouse-controlled shooting
- OBJ model loading
- Keyboard and mouse input handling
- Real-time 3D transformations

## Controls

| Input | Action |
|---|---|
| `W A S D` | Control airplane |
| `Mouse` | Aim |
| `Left Mouse Button` | Fire |
| `F / G` | Toggle floodlight |

## Technologies

- C++
- OpenGL
- GLSL
- GLM
- OBJ
